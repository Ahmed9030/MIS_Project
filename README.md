# Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Ahmed9030/MIS_Project.git
   ```
2. Navigate into the project directory:
   ```bash
   cd MIS_Project
   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
